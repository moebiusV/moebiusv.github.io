# moebiusv

I'm an open source developer working in Linux and BSD. I've contributed to Debian, to the Linux and FreeBSD kernels, and to the newLisp programming language. The projects below run from compilers and Unix history to cryptography, tools for the command line, and devices on the network.

## Defensive coding

**Bringing military grade into the modern age.**

Ada was commissioned by the US Department of Defense for software that can't be allowed to fail. These projects carry that discipline to today's Linux, BSD, and macOS.

- [imp72](https://github.com/moebiusV/imp72) — Edgar "Ned" Irons's extensible systems language, developed at the NSA, where it ran their Folklore time-sharing system. Walter Bilofsky's 1973 PDP-10 implementation, rebuilt on LLVM for Linux, BSD, and macOS.
- [ada-on-alpine](https://github.com/moebiusV/ada-on-alpine) — a complete Ada development toolchain packaged for Alpine Linux.
- [imsg-ada](https://github.com/moebiusV/imsg-ada) — Ada implementation of the OpenBSD imsg wire protocol and API for inter-process communication.
- [libsodium-ada](https://github.com/moebiusV/libsodium-ada) — Ada wrapper for the libsodium cryptography library.
- [mustache-ada](https://github.com/moebiusV/mustache-ada) — Ada implementation of the Mustache template language and API.
- [Ada functional style guidelines](ada-style-guidelines.html) — a style guide for functional-style Ada, with every example compiled with GNAT.

## Computer archaeology

- [pdp64](https://github.com/moebiusV/pdp64) — the PDP-11 architecture extended to 64 bits and SMP.
- [pcc](https://github.com/moebiusV/pcc) (fork) — the Portable C Compiler, with a PDP-11 focus.
- [v7unix-toolchain](https://github.com/moebiusV/v7unix-toolchain) — the Research Unix V7 cross-compiler (cc, as, ld, lex, yacc, make) for modern systems.
- [prebsd](https://github.com/moebiusV/prebsd) — fetch and run Research Unix V4, V5, V6, V7, and 32V on the SIMH emulator (PDP-11/70, VAX-11/780).
- [filsys](https://github.com/moebiusV/filsys) — a FUSE driver for Unix disk images from 1969 to 1989, with full read/write, from Version 0 to Version 10.

## AI

- [hbnf](https://github.com/moebiusV/hbnf) — a parser generator and compiler-compiler for the rest of us, supporting many programming languages.
- [cngpt](https://github.com/moebiusV/cngpt) — nanoGPT in C: OpenBLAS matmul, full backprop, and a compiler benchmark harness.
- [cugpt](https://github.com/moebiusV/cugpt) — C translations of microgpt: a tape-autograd version and a BLAS manual-backprop version.

## Business and productivity

CSV is the universal business interchange format. `csv` makes it easy to use securely, safely, and comfortably from the Unix command line and in scripts.

- [winless](https://github.com/moebiusV/winless) — a less pager for Windows, with annotation and editing facilities based on vim.
- [buildabook](https://github.com/moebiusV/buildabook) — automate building a printable book from Markdown and Typst files, with cover, table of contents, footnotes, and more.
- [ytran](https://github.com/moebiusV/ytran) — fetch YouTube transcripts, clean them up with Claude, and store searchable summaries in a local SQLite database.
- [bs3](https://github.com/moebiusV/bs3) — an interactive terminal browser for SQLite databases, with vi-style navigation and CGA colors.
- [csv](https://github.com/moebiusV/csv) — a Unix-style CSV processor with familiar head, tail, cut, grep, sort, and more. It is fully CSV-aware, with smart header and comment handling, and built for pipes.

## Home automation, robotics, and device control

- [bepsi](https://github.com/moebiusV/bepsi) — code for the DCTRL Bepsi machine: pay crypto, get a beverage.
- [seatuya](https://github.com/moebiusV/seatuya) — a C library with a stable ABI for local Tuya smart-device control, usable from any language with FFI.
- [tuyapp](https://github.com/moebiusV/tuyapp) (fork) — a C++ client library for the local Tuya API.
