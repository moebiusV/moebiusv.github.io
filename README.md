# moebiusv

I work in open source on Linux and BSD. Over the years I've contributed to Debian, the Linux kernel, the FreeBSD kernel, OpenBSD, and the newLisp programming language. Lately I've been working on Alpine Linux.

## Defensive coding

**Bringing military grade into the modern age.**

Ada was written for the US Department of Defense (MIL-STD-1815). These projects bring that discipline to Linux, BSD, and macOS.

- [imp72](https://github.com/moebiusV/imp72): Edgar "Ned" Irons's extensible systems language, developed at the NSA and used for their Folklore time-sharing system. Walter Bilofsky's 1973 PDP-10 implementation, ported to LLVM for Linux, BSD, and macOS.
- [ada-on-alpine](https://github.com/moebiusV/ada-on-alpine): a complete Ada development toolchain packaged for Alpine Linux.
- [imsg-ada](https://github.com/moebiusV/imsg-ada): Ada implementation of the OpenBSD imsg wire protocol and API for inter-process communication.
- [soja](https://github.com/moebiusV/soja) *(wip)*: an IRC bouncer in Ada 2022, translated from soju. *We are all sojas now.*
- [libsodium-ada](https://github.com/moebiusV/libsodium-ada): Ada wrapper for the libsodium cryptography library.
- [mustache-ada](https://github.com/moebiusV/mustache-ada): Ada implementation of the Mustache template language and API.

## Computer archaeology

- [pdp64](https://github.com/moebiusV/pdp64): the PDP-11 architecture extended to 64 bits and SMP.
- [pcc](https://github.com/moebiusV/pcc) (fork): the Portable C Compiler, with a PDP-11 focus.
- [v7unix-toolchain](https://github.com/moebiusV/v7unix-toolchain): the Research Unix V7 cross-compiler (cc, as, ld, lex, yacc, make) for modern systems.
- [prebsd](https://github.com/moebiusV/prebsd): fetch and run Research Unix V4, V5, V6, V7, and 32V on the SIMH emulator (PDP-11/70, VAX-11/780).
- [filsys](https://github.com/moebiusV/filsys): a FUSE driver for Unix disk images from 1969 to 1989, Version 0 to Version 10, with full read/write.

## AI

- [hbnf](https://github.com/moebiusV/hbnf): a parser generator and compiler-compiler supporting many programming languages.
- [cngpt](https://github.com/moebiusV/cngpt): nanoGPT in C, with OpenBLAS matmul, full backprop, and a compiler benchmark harness.
- [cugpt](https://github.com/moebiusV/cugpt): C translations of microgpt, one with tape autograd and one with BLAS manual backprop.

## Business and productivity

CSV is the universal business interchange format. The csv tool lets you use it securely, safely, and easily from the Unix command line and in scripts.

- [winless](https://github.com/moebiusV/winless): a less pager for Windows, with annotation and editing based on vim.
- [bepsi](https://github.com/moebiusV/bepsi) *(wip)*: automated payments for real-world goods. Pay crypto, get a beverage.
- [buildabook](https://github.com/moebiusV/buildabook): build a printable book from Markdown and Typst files, with cover, table of contents, and footnotes.
- [ytran](https://github.com/moebiusV/ytran): fetch YouTube transcripts, clean them up with Claude, and store searchable summaries in a local SQLite database.
- [bs3](https://github.com/moebiusV/bs3): an interactive terminal browser for SQLite databases, with vi-style navigation and CGA colors.
- [csv](https://github.com/moebiusV/csv): a Unix-style CSV processor with head, tail, cut, grep, sort, and more. It is CSV-aware, handles headers and comments, and works in pipes.

## Home automation, robotics, and device control

- [bepsi](https://github.com/moebiusV/bepsi) *(wip)*: code for the DCTRL Bepsi machine. Pay crypto, get a beverage.
- [seatuya](https://github.com/moebiusV/seatuya): a C library with a stable ABI for local Tuya smart-device control, usable from any language with FFI.
